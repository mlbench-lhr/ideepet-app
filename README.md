# idee_pet

Comando para conflito do MOBX: dart run build_runner build --delete-conflicting-outputs

Mudança na native splash: dart run flutter_native_splash:create --path=flutter_native_splash.yaml

Mudança no icone android: dart run flutter_launcher_icons:main

Build apk
flutter clean 
flutter build apk --release

Criar feature:
./make_feature.sh

esse comando irá solicitar o nome da feature que deve ser com snake_case e cria a estrutura básica de uma feature
